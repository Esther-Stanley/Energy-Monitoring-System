# Energy-Monitoring-System
A real-time Energy Monitoring System using ESP32 and PZEM-004T to measure and display voltage, current, and power consumption on a 16×2 LCD display.

The Energy Monitoring System is a microcontroller-based project developed to monitor electrical parameters in real time. The system uses an ESP32 development board interfaced with a PZEM-004T energy monitoring sensor to measure voltage, current, and power consumption.

The measured values are processed by the ESP32 and displayed on a 16×2 LCD, providing a simple and convenient way to monitor the electrical parameters of a connected load.

This project was developed as a first-semester hands-on project in Electronics and Communication Engineering, with the objective of gaining practical experience in embedded systems, sensor interfacing, and microcontroller programming.

Components Used :

ESP32 Development Board – Main microcontroller responsible for processing sensor data.

PZEM-004T Energy Monitoring Module – Measures electrical parameters.

Current Transformer (CT) – Used for current measurement.

16×2 LCD Display – Displays the measured electrical parameters.

Breadboard – Used for circuit assembly and prototyping.

Jumper Wires – Used for electrical connections.
